# 🌙🚫 Possum（假寐）

**让你的 Mac 假装在休息，实际在偷偷干活。**

Possum 名字来自英语习语 *playing possum*（负鼠装死）——正是「假寐」的地道表达。它是一款极简的 macOS 工具：一键进入「工作模式」，阻止系统休眠的同时全屏显示一个逼真的时钟屏保。无论是让 AI Agent（如 Claude Code）通宵跑任务，还是避免演示时电脑尴尬锁屏，Possum 都能优雅搞定。

---

## ✨ 特性

- **防休眠** — 双重电源断言（系统 + 屏幕），只要开盖就不会睡
- **假屏保** — 全屏时钟，覆盖所有显示器，缓慢漂移防烧屏，看起来就像系统锁屏
- **防误触** — 开启后需长按 Esc 2 秒或点击屏幕按钮才能退出，再也不怕猫踩键盘
- **即开即走** — 设好延时，起身离开，电脑自动进入屏保状态
- **零权限** — 不需要辅助功能权限，不需要管理员密码
- **自动清理** — App 退出（含崩溃）自动释放电源断言，不留后遗症

## 🚀 安装

### 从 Release 下载

前往 [Releases](../../releases) 下载最新的 `Possum.app.zip`，解压后拖入「应用程序」文件夹。

### 从源码构建

```bash
git clone https://github.com/你的用户名/possum.git
cd possum
./scripts/make-app.sh
open build/Possum.app
```

要求 macOS 13+ 和 Swift 5.9+。

---

## 🎮 使用方法

1. 打开 Possum，设置进入屏保的延时（默认 5 秒）
2. 按需开启「防误触模式」
3. 点击 **开始工作模式**
4. 倒计时结束 → 全屏时钟屏保启动 → 系统不再休眠
5. 退出：轻轻动鼠标即可（防误触模式下需长按 Esc 或点击按钮）

## 🎯 适用场景

| 场景 | 效果 |
|------|------|
| AI Agent 通宵跑代码 | 屏幕亮着但看起来在休息，不会被自动睡眠打断 |
| 下载/渲染等长任务 | 确保系统不会中途休眠 |
| 办公室「假装已走」| 全屏时钟看起来像是已锁屏 |
| 演示/展览防锁屏 | 比系统设置"永不休眠"更优雅 |

---

## ⚠️ 注意

- **合盖会休眠**：软件无法对抗物理合盖，请保持屏幕打开
- 插拔显示器自动适配，无需手动操作
- 这不是安全锁屏工具——真正的锁屏请用系统自带功能

---

## 🛠 技术细节

- 纯 Swift + SwiftUI，通过 Swift Package Manager 构建
- 使用 `IOPMAssertionCreateWithName` 创建电源断言
- 屏保窗口 level 为 `.screenSaver`，覆盖 Dock 和菜单栏
- 事件监听区分 global/local monitor，确保前台和后台都能响应
